# Document after implementation

As soon as you finish implementing the last ticket of a spec (after `code-review`, before opening the PR), ask the operator whether to run the `document-feature` skill.

- Always ask. Don't skip the question, even for small changes.
- Don't run the skill without the operator's confirmation.
- "Last ticket" means the last one implemented in this work, not the last one closed on GitHub: tickets only close when the PR merges.

See [docs/dev/workflow.md](../../docs/dev/workflow.md) (step 6).
